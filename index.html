How this plan is calculated

Best fit sorts pieces longest first and chooses the tightest board that fits. List order cuts each part from the current board before opening another. A separation cut uses one kerf. An exact end fit needs no separation cut. All stock has the same usable length. This heuristic does not guarantee the fewest boards.
